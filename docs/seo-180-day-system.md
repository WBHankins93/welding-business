# DJN Services SEO 180-Day System

This plan is intentionally lightweight for a stable local-service business and focuses on consistency over frequent campaign churn.

## Cadence Overview (180 days)

- **Weekly (15-30 min):**
  - Publish one Google Business Profile (GBP) photo from a real job.
  - Respond to all new reviews.
  - Verify hours/phone are still correct in GBP.

- **Monthly (1-2 hours):**
  - Add one short project update to the site (services/about/home as relevant).
  - Review Search Console for top queries, pages, and indexing issues.
  - Refresh internal links to contact/booking from high-traffic pages.

- **Every 90 days:**
  - Review and improve top 3 pages by impressions.
  - Add FAQ entries for recurring customer questions.
  - Re-check LocalBusiness structured data in Rich Results Test.

- **At 180 days:**
  - Compare baseline vs current leads/calls/forms.
  - Keep tactics that increased calls and bookings.
  - Retire low-impact updates and repeat the cycle.

## Core local SEO priorities

1. Keep NAP (name/address/phone) identical across website + GBP.
2. Continue collecting and replying to reviews.
3. Maintain high-quality project photos.
4. Keep service area language and job-type copy specific.
5. Preserve fast page loads and clean technical SEO (sitemap/robots/metadata).
